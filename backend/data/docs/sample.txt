Type: Personal / Portfolio Project
Domain: Agentic AI / Multi-Agent Systems / Productivity Automation

Description:
OrchesterAI is a stateful multi-agent orchestration framework built using LangGraph and LangChain. It coordinates 7 specialized LLM agents operating as a Directed Acyclic Graph (DAG) with autonomous conditional edge routing and type-safe inter-agent schema validation.

Key Features:
- 7 specialized LLM agents, each with defined roles and scoped capabilities.
- Stateful DAG orchestration with conditional routing between agents.
- Type-safe inter-agent communication using schema validation.
- Autonomous email and calendar execution layer:
  * Integrates with Gmail, Outlook, and Calendar APIs.
  * OAuth 2.0 authentication for secure API access.
  * Fuzzy-match contact resolution for natural language email targeting.
- Built with FastAPI backend and Gradio frontend.
- End-to-end distributed tracing via LangSmith for full agent observability.
